# 荡绳飞跃上手修复验收

日期：2026-10-16。仅本地，未发布。

## 反馈与修复

用户反馈难以理解玩法且反复掉落。实际代码的摆动角度与角色位置不同步，左转向还存在角度跳变。修复位置连续性，脚底与落地线对齐，加入真实轨迹预测、绿色放手按钮、宽平台和当前岛重试。失败时解释过早/往回荡或飞过头；飞行与自动抓下一根绳时禁用放手。固定物理帧率，失焦暂停。

## 验证

- scripts/check-pixel-physics.cjs 直接执行 HTML 内实际函数：720 个时机的预测与落地结果逐个一致；随机间距最小、中间、最大三种情况下各连续 20 岛；所有摆动转向连续；失败后保留第 20 岛；30、60、120 Hz 物理速度一致。原射箭、接蛋、钢丝回归通过。
- 实际 Chromium：通过按钮、空格、Canvas 触控连续完成 5 座岛；故意失败后显示原因、重试仍为第 5 岛；失焦与恢复生效。
- 900×640、390×844、390×480、320×380、844×390：无横向溢出，放手按钮完整可见。
- 门户游戏 iframe：开始、绿色时放手上岛、外层重开；无浏览器脚本错误。
- npm run build 完成，113 款静态检查通过；112 款初始化通过，shellgame 维持已有 mock 跳过。
