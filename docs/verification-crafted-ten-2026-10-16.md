# 十款精绘卡通像素改造验收（2026-10-16）

## 范围与视觉

用户反馈前几款可爱、后续改造随意。本轮选择此前未改造的 flappy、tetris、2048、breakout、memory、minesweeper、match3、farmclicker、whackmole、sokoban，共 10 款；不是随机抽样。累计 34 款改造，总数仍为 113。

每款将像素绘画用于实际游戏物件，而不仅是外框：小鸟羽毛、水管、糖果积木、木纹数字盘、糖霜饼干、野餐牌、草皮、六种果蔬、农场、表情地鼠、兔子和木箱。绘图为内置矩形像素图集，Canvas/SVG 共用绘制逻辑，保持单 HTML、无外部素材依赖。颜色各有主题；游戏注册名称与路径保持原有名称，游戏内增加主题副标题。

预览：local-previews/pixel-crafted-ten-2026-10-16.html；实际截图 docs/design/2026-10-16/crafted-*.png。

## 自动回归

新增 scripts/check-crafted-ten.cjs，执行真实 HTML 内脚本，在测试环境中构造边界状态；测试桥不会进入发布文件。加入 npm run test:gameplay 与 prebuild。

- 小鸟：过管计分、撞地、重开、扇翅；物理改为固定 60 Hz。
- 方块：消行计分、仅落下获得的分数也记录最佳、重开清理时间累积，避免硬降触发死亡后同一空格立即重开。
- 2048：一次合并规则、达成 2048 后继续保留棋盘，结束状态与获胜提示分开；格子用 CSS Grid 随窗口即时缩放。
- 打砖块：发射、碰撞得分、清盘换轮、三命结束；固定 60 Hz。
- 翻牌：重开计时仍运行、取消过期翻回回调、八对全完成。
- 扫雷：首击安全、固定随机源不死循环、胜负、重开清理旗标模式。
- 三消：300 个初始盘无三连且存在合法交换；固定随机源可生成；交换得分；终局与重开取消旧连锁回调。
- 农场：成熟后始终六块田（消除递归渲染的重复节点）、收获、空田升级保留种子钱、目标达成界面更新。
- 地鼠：金鼠 +3、一次出洞不能重复得分、倒计时与重开。
- 推箱子：撤销；对原有五关搜索解法并用实际移动执行；总步数不再切关重复累加。
