# 黑白像素动态海报 · 第一版

用户希望先尝试一版无文案的黑白像素粒子宣传海报，带 PPT 演示或游戏式交互，可以在 GitHub 展示。

这次的视觉构思是：漂浮的岛屿、粒子构成的光门、一位旅人逐渐拥有两位同行者，随后出现另一条道路。人物、地图和粒子均为程序绘制的原创图形，没有使用宝可梦角色或外部素材。左上方保留文案空间，目前不填文字。

- 交互版本：[GitHub Pages](https://awiggy.github.io/game-hub/poster/)
- 源文件：`poster/index.html`、`poster/style.css`、`poster/main.js`
- GitHub README 展示：`preview.gif`，由真实网页 Canvas 的 180 帧生成。
- 本地预览：`npm run dev` 后打开 `/poster/`。
- 发布：和门户一起运行 `npm run build`，输出 `dist/poster/index.html`；不进入游戏注册表，游戏数量保持 50 款。

## 交互

- 自动循环三个场景，每轮 24 秒。
- 下方三个菱形按钮选择独行、同行、岔路。
- 指针移动产生视差并扰动附近的光门粒子；点击画面释放扩散波纹。
- 空格暂停／继续；左右方向键切换场景；右下角可重播。
- 系统开启“减少动态效果”时默认暂停，仍可以主动播放和切换场景。

## 验证

已用 Chrome 验证场景切换、键盘操作、暂停保持画面、点击波纹、手机无横向溢出与减少动态效果模式。页面无未捕获脚本错误。50 款游戏的静态检查与包含海报入口的生产构建通过。

这是视觉方向探索，尚未加入宣传文案或完整游戏流程。
