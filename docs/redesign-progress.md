编辑 `docs/redesign-status.json`，为每款填写状态、批次和验收记录，再运行 `npm run progress`。构建前自动验证目录覆盖、重复标识和证据文件，避免漏记或重复计入。新增游戏需要同时增加待改造条目，移出游戏需要转入归档清单。
