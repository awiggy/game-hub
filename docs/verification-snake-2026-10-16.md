# 贪吃蛇苹果花园试版验收

日期：2026-10-16。范围仅限 snake 内部游戏及对应介绍。参考用户提供的彩色卡通像素游戏封面：青绿蛇、红苹果、青绿格子与花草围边。

## 实现

- 单 HTML 文件，Canvas 整数像素绘图，没有外部字体、图片或脚本依赖。
- 明亮奶油色界面、青绿棋盘、连续蛇身与方向眼睛、像素红苹果、吃果实粒子；开场、暂停和结算状态可见。
- 保留 24×24、每果 +10、140ms 起步/最低 70ms、snake-best 纪录键；新增方向按钮与失焦暂停。
- 修正原版开场自动运行、暂停无反馈、尾格误判；增加两步转向缓存与满盘胜利，避免放置食物死循环。

## 验证结果

- `npm run build` 通过：注册表生成、113 个游戏静态检查、112 个游戏初始化冒烟、Vite 生产打包。现有 shellgame 继续沿用其已声明的 mock 跳过规则。
- Chromium 实际加载原 HTML，无脚本异常。确定性帧推进与固定随机数验证开场不移动、吃果实 +10、暂停棋盘冻结、按钮/空格继续、方向键/WASD、撞墙结算、重开归零、失焦暂停、刷新保留纪录。
- 检查 320×380、390×480、768×430、900×640、844×390：无横向/纵向溢出、棋盘保持正方形。已修复低高度桌面窗口侧栏造成的溢出。
- 方向按钮与 pointer 滑动事件通过；手机门户 iframe 额外用 Chromium CDP 注入触摸序列验证可操作、暂停和门户外层重开，无异常。
- 对实际游戏脚本在临时 VM 中暴露函数进行边界验证：合法进入将腾空的尾格、咬身体结束、不能反向、最多缓存两次转向、满盘进入胜利状态。
- 实际看过桌面与手机预览。浏览器为自动化 Chromium；未在实体手机 Safari 上实测。
